# 正则表达式入门讲义

正则表达式（Regular Expression，简称 **Regex**）是一种用于**匹配、查找和处理字符串**的规则。

例如，`[0-9]+` 可以匹配一个或多个连续数字，在 `abc123def` 中，它可以用于匹配 `123`。

---

## 常用符号速查表

| 符号 | 含义 | 示例 |
|---|---|---|
| `abc` | 普通字符 | `abc` |
| `.` | 任意一个字符 | `a.c` |
| `|` | 或者 | `a|b` |
| `[abc]` | `a`、`b`、`c` 中任意一个 | `[abc]` |
| `[a-z]` | 一个小写字母 | `[a-z]` |
| `[0-9]` | 一个数字 | `[0-9]` |
| `*` | 前面的内容出现 0 次或多次 | `a*` |
| `+` | 前面的内容出现 1 次或多次 | `a+` |
| `?` | 前面的内容出现 0 次或 1 次 | `a?` |
| `()` | 将内容组成一个整体 | `(ab)+` |
| `\` | 将特殊标识符转义为普通字符 | `\*`、`\+`、`\?` |

---

## 常用的匹配规则

### 1. 普通字符

普通字母和数字通常表示**匹配它自己**。

例如，正则表达式 `abc` 可以匹配字符串 `abc`。

在字符串 `123abcdef` 中，`abc` 可以用于匹配其中连续出现的三个字符 `abc`。

---

### 2. `|` 与 `[]`：选择不同的匹配内容

`|` 表示**或者**，也就是匹配左边或右边的内容。

例如：

```regex
a|b
```

表示匹配 `a` 或 `b`。

再例如：

```regex
cat|dog
```

可以匹配：

```text
cat
dog
```

`|` 左右两边不仅可以是单个字符，也可以是完整的字符串或其他正则表达式。

例如：

```regex
apple|banana
```

可以匹配：

```text
apple
banana
```

---

方括号 `[]` 表示**匹配括号中任意一个字符**。

例如：

```regex
[abc]
```

可以匹配：

```text
a
b
c
```

但不能匹配 `d`。

从本质上来说，`[]` 可以理解为**多个单字符之间的“或”**。

例如：

```regex
[abc]
```

在匹配单个字符时，可以理解成：

```regex
a|b|c
```

也就是说，`[]` 是多个单字符选择的一种更简洁的写法。

例如：

```regex
h[ae]llo
```

可以匹配：

```text
hallo
hello
```

但不能匹配 `hillo`。

#### 字符范围

在 `[]` 中可以使用 `-` 表示范围。

例如：

```regex
[a-z]
[A-Z]
[0-9]
[a-zA-Z0-9]
```

它们分别表示：

```text
任意一个小写英文字母
任意一个大写英文字母
任意一个数字
任意一个英文字母或数字
```

需要注意，`[]` 一次只匹配**一个字符**。

例如，`[abc]` 表示 `a`、`b`、`c` 三选一，而不是匹配字符串 `abc`。

因此可以简单理解：

```text
a|b|c    多个单字符之间使用“或”
[abc]    上面写法的简化形式
```

---

### 3. `*`、`+`、`?`：控制出现次数

这三个符号都用来控制**前面的内容出现多少次**。

#### `*`：出现 0 次或多次

`a*` 表示 `a` 可以出现 0 次、1 次、2 次……

因此可以匹配：

```text
空字符串
a
aa
aaa
```

例如：

```regex
ab*c
```

可以匹配：

```text
ac
abc
abbc
abbbc
```

因为 `b*` 表示 `b` 可以出现任意多次，也可以一次都不出现。

#### `+`：出现 1 次或多次

`a+` 表示 `a` 至少出现一次。

因此可以匹配：

```text
a
aa
aaa
aaaa
```

但不能匹配空字符串。

例如：

```regex
[0-9]+
```

表示一个或多个连续数字。

所以在 `abc12345def` 中，可以用于匹配 `12345`。

#### `?`：出现 0 次或 1 次

`a?` 表示 `a` 可以不出现，也可以出现一次。

例如：

```regex
colou?r
```

其中 `u?` 表示 `u` 可有可无。

因此它可以匹配：

```text
color
colour
```

但不能匹配 `colouur`。

#### 三者总结

| 符号 | 含义 | 出现次数 |
|---|---|---|
| `*` | 可以没有，也可以出现很多次 | 0 次或多次 |
| `+` | 至少出现一次 | 1 次或多次 |
| `?` | 可有可无 | 0 次或 1 次 |

---

### 4. `.`：任意字符

`.` 表示**任意一个字符**。

例如：

```regex
a.c
```

可以匹配：

```text
abc
aac
a1c
a-c
a c
```

因为中间的 `.` 可以对应任意一个字符。

但是 `ac` 不能被 `a.c` 匹配，因为 `.` 必须对应一个实际存在的字符。

---

### 5. `()`：分组

圆括号 `()` 用于把若干字符或规则组合成一个整体。

例如：

```regex
(ab)+
```

这里的 `+` 作用于整个 `ab`。

因此它可以匹配：

```text
ab
abab
ababab
```

而：

```regex
ab+
```

中的 `+` 只作用于 `b`。

因此它可以匹配：

```text
ab
abb
abbb
abbbb
```

所以 `(ab)+` 和 `ab+` 含义完全不同，前者表示 **`ab` 这个整体重复**，后者表示 **一个 `a` 后面跟一个或多个 `b`**。

`()` 也经常和 `|` 一起使用。

例如：

```regex
(apple|banana)
```

表示 `apple` 或 `banana`。

再例如：

```regex
I like (cats|dogs)
```

可以匹配：

```text
I like cats
I like dogs
```

---

### 6. `\`：转义符

反斜杠 `\` 可以用于**转义正则表达式中的特殊标识符**。

也就是说，如果某个符号本来具有正则表达式中的特殊含义，在前面加上 `\` 后，就可以把它作为普通字符进行匹配。

例如：

```regex
\*
\+
\?
\[
\(
\|
\\
```

它们分别用于匹配：

```text
*
+
?
[
(
|
\
```

因此可以简单理解成：

```text
\特殊标识符
```

表示**取消这个标识符原本的正则含义，把它作为普通字符使用**。

---

## 综合例子

前面的符号通常不会单独使用，而是会组合起来构成完整的正则表达式。

例如：

```regex
[a-z]+
```

表示**一个或多个连续的小写字母**。

可以匹配：

```text
hello
abc
regex
```

例如：

```regex
[0-9]+
```

表示**一个或多个连续数字**。

可以匹配：

```text
123
2026
10086
```

再例如：

```regex
-?[0-9]+
```

可以匹配：

```text
123
-123
25
-25
```

其中 `-?` 表示 `-` 出现 0 次或 1 次，而 `[0-9]+` 表示至少出现一个数字。

因此整个表达式表示：

**一个可选的负号，后面跟一个或多个数字。**

---

再看：

```regex
[a-zA-Z][a-zA-Z0-9]*
```

可以拆成两部分。

第一部分 `[a-zA-Z]` 表示第一个字符是一个英文字母。

第二部分 `[a-zA-Z0-9]*` 表示后面可以有任意多个字母或数字，也可以什么都没有。

因此可以匹配：

```text
a
hello
abc123
A123
Test2026
```

---

再例如：

```regex
(ab|cd)+
```

先看 `(ab|cd)`，表示 `ab` 或 `cd`。

外面的 `+` 表示前面的整个分组至少出现一次。

所以可以匹配：

```text
ab
cd
abab
abcd
cdab
cdcd
ababcd
```

这个例子同时使用了 `()`、`|` 和 `+`：

```text
()：分组
| ：或者
+ ：重复一次或多次
```

因此阅读正则表达式时，可以按照这样的顺序：

**先看 `[]` 和 `()` 确定每一部分表示什么，再看 `|` 确定有哪些选择，最后看 `*`、`+`、`?` 判断前面的内容允许出现多少次。**
