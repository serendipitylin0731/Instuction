# Markdown 文本文档入门讲义

Markdown 是一种用于编写**格式化文本文档**的轻量级标记语言

简单来说，我们只需要在普通文字前后加上一些符号，就可以表示标题、列表、链接、代码块等内容，而不需要像 Word 一样逐项调整格式

例如：

```markdown
# Markdown 文本文档入门讲义

Markdown 是一种用于编写**格式化文本文档**的轻量级标记语言
```

渲染之后就对应这这篇文档的标题和第一行字

Markdown 文件的后缀名为 `.md`，本仓库中的 `README.md` 和各篇讲义都是 Markdown 文件。

---

## 使用准备

Markdown 本质上仍然是纯文本，所以可以使用任意文本编辑器进行编写，这里推荐使用 vscode。

在 vscode 中新建文件，把文件后缀名设置为 `.md`，就可以开始编写。点击编辑器右上角的预览按钮，或者使用快捷键 `Ctrl + Shift + V`，可以查看当前文档渲染后的效果。

> tip：Markdown 的源文件和渲染结果是两种不同的显示方式。源文件中写的是带有标记符号的文字，渲染后才会显示出标题、粗体、表格等格式。

## 常用的文本格式

### 1. 标题

在一行文字前添加 `#` 和一个空格，就可以把这一行设置为标题。

标题一共分为六级，`#` 的数量越多，标题的级别越低，显示出来的字号通常也越小。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

一般一篇文档只使用一个一级标题作为文章标题，后面的内容再根据层级使用二级、三级标题。

需要注意，`#` 后面要留一个空格。下面这种写法在部分编辑器中可能不会被识别为标题：

```markdown
#没有空格的标题
```

---

### 2. 段落与换行

普通文字不需要添加任何符号，直接编写即可。

```markdown
这是一段普通文字。

这是另一段普通文字。
```

两个段落之间需要留出一个空行。

如果只在源文件中按一次回车，许多 Markdown 渲染器仍然会把前后内容显示在同一段中。因此需要另起一段时，最简单稳定的方式就是**中间留一个空行**。

如果确实想在同一个段落中强制换行，可以在上一行末尾添加两个空格，或者使用 html 语法  `<br>`：

```markdown
第一行  
第二行

第三行<br>
第四行
```

---

### 3. 粗体、斜体与删除线

在文字两边添加不同的符号，可以改变文字的显示格式。

```markdown
**这是粗体文字**

*这是斜体文字*

***这是粗斜体文字***

~~这是删除线文字~~
```

它们渲染后的效果如下：

**这是粗体文字**

*这是斜体文字*

***这是粗斜体文字***

~~这是删除线文字~~

有些 Markdown 编辑器还支持使用 `==` 标记高亮：

```markdown
==这是高亮文字==
```

但是高亮并不属于所有 Markdown 渲染器都支持的通用语法，因此同一个文件在不同平台上打开时，可能会直接显示两边的 `==`。

---

### 4. 引用

在一行文字前添加 `>` 和一个空格，就可以表示引用或补充说明。

```markdown
> 这是一段引用。
```

渲染后的效果如下：

> 这是一段引用。

连续多行引用时，每一行都可以添加 `>`：

```markdown
> 第一行引用
>
> 第二行引用
```

引用中还可以继续使用粗体、链接、行内代码等其他 Markdown 语法。

## 列表

### 1. 无序列表

在每一项内容前添加 `-` 和一个空格，就可以创建无序列表。

```markdown
- 苹果
- 香蕉
- 西瓜
```

渲染后的效果如下：

- 苹果
- 香蕉
- 西瓜

也可以使用 `*` 或 `+` 创建无序列表，但是为了让同一篇文档的格式保持统一，建议固定使用 `-`。

### 2. 有序列表

在每一项前添加数字、英文句号和一个空格，就可以创建有序列表。

```markdown
1. 打开 vscode
2. 新建 Markdown 文件
3. 编写并预览文档
```

渲染后的效果如下：

1. 打开 vscode
2. 新建 Markdown 文件
3. 编写并预览文档

### 3. 多级列表

在列表项前增加缩进，可以创建多级列表。

```markdown
- 水果
  - 苹果
  - 香蕉
- 饮料
  - 牛奶
  - 咖啡
```

可以简单理解为：缩进相同的内容处于同一级，缩进更深的内容属于上一项的子列表。

> tip：不同编辑器对缩进的处理可能略有区别，通常使用两个或四个空格都可以。编写同一个列表时，应当保持缩进方式一致。

### 4. 任务列表

在无序列表的基础上添加 `[ ]` 或 `[x]`，可以创建任务列表。

```markdown
- [x] 安装 vscode
- [x] 新建 Markdown 文件
- [ ] 完成讲义
```

其中 `[ ]` 表示未完成，`[x]` 表示已经完成。

## 链接与图片

### 1. 链接

链接的基本语法为：

```markdown
[显示文字](链接地址)
```

例如：

```markdown
[GitHub 官网](https://github.com/)
```

渲染后只会显示方括号中的文字，点击它就会跳转到圆括号中的地址。

链接也可以指向本地的其他文件。例如，从本篇讲义跳转到同一文件夹下的正则表达式讲义，可以写成：

```markdown
[正则表达式入门讲义](regex正则表达式入门讲义.md)
```

这种地址叫作**相对路径**。它以当前文件所在的位置为起点，因此移动文件之后，原来的链接可能需要一起修改。

### 2. 图片

图片的语法和链接非常相似，只需要在前面多加一个 `!`：

```markdown
![图片说明](图片地址)
```

例如：

```markdown
![vscode 图标](https://example.com/vscode.png)
```

其中方括号中的图片说明通常不会直接显示，但在图片加载失败时可以帮助读者理解这里原本是什么内容。

图片地址既可以使用网络链接，也可以使用本地相对路径：

```markdown
![操作步骤](images/step1.png)
```

## 代码

### 1. 行内代码

在一小段文字两边添加反引号 `` ` ``，可以把它标记为行内代码。

```markdown
Markdown 文件的后缀名为 `.md`。
```

行内代码适合表示文件名、命令、变量名和较短的语法。

需要注意，反引号 `` ` `` 和单引号 `'` 不是同一个符号。反引号通常位于键盘左上角、数字 `1` 的左边。

### 2. 代码块

如果需要展示多行代码，可以在代码前后各使用三个反引号。

````markdown
```python
print("Hello, Markdown!")
```
````

开头三个反引号后面的 `python` 用于指定代码语言，编辑器会根据语言添加语法高亮。

常见的语言标识包括：

```text
python
cpp
bash
powershell
json
markdown
text
```

如果代码只是普通文本，不需要语法高亮，可以使用 `text`，也可以不填写语言。

## 表格

表格使用竖线 `|` 分隔每一列，并使用 `---` 分隔表头和正文。

```markdown
| 工具 | 用途 | 文件后缀 |
|---|---|---|
| Markdown | 编写文档 | `.md` |
| Mermaid | 绘制图表 | `.mmd` |
```

渲染后的效果如下：

| 工具 | 用途 | 文件后缀 |
|---|---|---|
| Markdown | 编写文档 | `.md` |
| Mermaid | 绘制图表 | `.mmd` |

源文件中的竖线不一定要完全对齐，只要每一行的列数对应即可。但是为了方便直接阅读源文件，内容较少时可以手动把它们对齐。

在分隔行中添加冒号，可以控制每一列的对齐方式：

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
|:---|:---:|---:|
| 内容1 | 内容2 | 内容3 |
| 内容111 | 内容222 | 内容333 |
```

渲染后的效果如下：
| 左对齐 | 居中对齐 | 右对齐 |
|:---|:---:|---:|
| 内容1 | 内容2 | 内容3 |
| 内容111 | 内容222 | 内容333 |

## 分割线

单独在一行中输入三个或更多的减号，可以创建一条分割线。

```markdown
---
```

分割线适合用于分隔不同部分的内容。为了避免它与其他语法混在一起，建议在分割线前后各留一个空行。

---

## 转义 Markdown 符号

如果想直接显示具有特殊含义的符号，而不希望它被渲染成 Markdown 格式，可以在符号前添加反斜杠 `\`。

例如：

```markdown
\*这段文字不会变成斜体\*
\# 这行文字不会变成标题
```

它们会显示为：

```text
*这段文字不会变成斜体*
# 这行文字不会变成标题
```

常见的需要转义的符号包括：

```text
\  `  *  _  {  }  [  ]  (  )  #  +  -  .  !  |
```

## 在 Markdown 中绘制流程图

一些 Markdown 编辑器支持直接渲染 Mermaid 图表。它的写法和普通代码块类似，只需要把代码语言设置成 `mermaid`。

````markdown
```mermaid
graph LR
    A["开始"] --> B["结束"]
```
````

渲染后的效果如下：

```mermaid
graph LR
    A["开始"] --> B["结束"]
```

Mermaid 并不是所有 Markdown 编辑器都默认支持的功能。如果无法显示，可以检查当前平台是否支持 Mermaid，或者安装对应的 vscode 扩展。

更详细的流程图语法可以阅读 [Mermaid 流程图入门讲义](meimaid流程图入门讲义.md)。

## 文档信息区

本仓库的讲义开头通常会出现下面这段内容：

```yaml
---
tags: Instruction
---
```

这部分称为 YAML Front Matter，可以用于记录标签、作者、日期等文档信息。

它通常必须放在文件的最开头。不同平台对 Front Matter 的支持不同，如果只是在 GitHub 或 vscode 中编写普通 Markdown 文档，也可以不添加这一部分。

## 综合例子

下面是一篇简单 Markdown 文档的完整源文件：

````markdown
# 学习记录

今天学习了 **Markdown** 的基本语法。

## 已完成内容

- [x] 标题
- [x] 列表
- [x] 链接
- [ ] 表格

## 常用链接

[打开 GitHub](https://github.com/)

## 示例代码

```python
print("Hello, Markdown!")
```

> 每次写完后记得打开预览，检查最终显示效果。
````

阅读 Markdown 源文件时，可以按照这样的顺序：

**先看标题确定文档结构，再看列表、引用和表格确定内容之间的关系，最后查看链接、图片和代码块中的具体信息。**

在实际编写时也不需要一次记住全部语法。先掌握标题、列表、链接、图片和代码块，已经足够完成大多数普通文档；忘记某种写法时，再回到前面的速查表查找即可。
