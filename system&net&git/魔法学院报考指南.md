# 魔法学院报考指南

### Step 1: 购买配置

在此[购买链接](https://u.wuhenlink.cc)进行注册

![](https://notes.sjtu.edu.cn/uploads/upload_8eaf8ba74cd118745247510e66610ba8.png)

然后在购买订阅处购买适合自己的流量包（推荐80G月租）

![](https://notes.sjtu.edu.cn/uploads/upload_d1030881b0c7a70fd833e289c502c5bf.png)

成功购买后，按照下图步骤复制自己的代理地址**配置码**（也可以使用第三个-配置文件）

==有些时候节点会出问题，及时到官网上看是否有公告，会有修复方法==

![](https://notes.sjtu.edu.cn/uploads/upload_fa8ef2edfc29c1de4b45a8342d616e76.png)


### Step 2：下载梯子客户端FlClash

点击链接[Clash for Windows](https://gh-proxy.org/https://github.com/fudomine/FlClashSpecial/releases/download/v0.8.90c/FlClash-1.8.90-windows-amd64.zip)下载安装包，解压缩之后直接双击运行（推荐移到桌面上方便找

**如果有风险提示**点击 `更多信息` 之后点击 `仍要运行` 即可（如图）

![](https://notes.sjtu.edu.cn/uploads/upload_3ae5f49e80b9628adb33969b5ec3fcb3.png)

![](https://notes.sjtu.edu.cn/uploads/upload_043f6d077aa6d07db91d762ce6ddbb18.png)


### Step 3：导入配置

进入之后会跳转这样的页面，选择左边第三个配置（如图）

![](https://notes.sjtu.edu.cn/uploads/upload_b4e57e9ba8462c1a36e4adc1ac063684.png)

你点进去之后应该是空的，点击右下角的加号，选择 `通过URL获取配置文件` ，然后输入你的**配置码**，配置好之后点击选中，就算启用了，但是还没有连接

![](https://notes.sjtu.edu.cn/uploads/upload_b33f48f86fa7d4094a3fee1c748cf2dc.png)

![](https://notes.sjtu.edu.cn/uploads/upload_d1148e6464352d1f1401e498b3b9cf4f.png)

### Step 3：连接梯子

当你需要使用GitHub或者其他外网网站时，开启梯子（千万不要用来看视频等高耗流用途，其他的网页访问一直开着都没关系，不然一下子就全用完了）回到左边第一个选项仪表盘，出站模式选择 `规则` ，右下角的三角单击启动连接，就会看到上面的流开始移动

![](https://notes.sjtu.edu.cn/uploads/upload_95290af0cca4b74fa5cc7037f21d0d49.png)


![](https://notes.sjtu.edu.cn/uploads/upload_a4ba61b5410542e29f5a1a671b66d06f.png)

这个时候选择左边的第二个就可以看到你的流是挂在哪一个地区了，如果某个地区爆红了就换一个地区，全爆红了就跟我说（因为肯定我也爆红了，不然你重启一下软件就能解决）一般推荐选美国，上这些网站会稳定一点

![](https://notes.sjtu.edu.cn/uploads/upload_80cc8396609d6356928e7c5a981c190d.png)
