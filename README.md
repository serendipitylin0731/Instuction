# 计算机工具使用指南

这里整理了一些计算机工具的零基础入门讲义，内容以平时真正会用到的操作为主。

如果你第一次接触这些工具，可以直接按照对应讲义从头操作；如果只是忘记了某个语法，也可以把它们当成速查手册使用。

---

## 文档编写

- [Markdown 文本文档入门讲义](doctype/markdown文本文档入门讲义.md)：学习标题、列表、链接、图片、代码块和表格等常用写法
- [正则表达式入门讲义](doctype/regex正则表达式入门讲义.md)：学习用规则匹配、查找和处理字符串
- [Mermaid 流程图入门讲义](doctype/meimaid流程图入门讲义.md)：学习在 Markdown 中绘制简单流程图

## 环境、网络与 Git

- [WSL Ubuntu 24.04 安装引导](system&net&git/Ubuntu24.04安装引导.md)：在 Windows 中安装并配置 Ubuntu 开发环境
- [魔法学院报考指南](system&net&git/魔法学院报考指南.md)：完成网络工具的安装与基础配置
- [Git 使用指南](system&net&git/git使用指南.md)：学习仓库、提交、分支和合并等基础操作

---

## 使用方法

可以直接在 GitHub 中打开对应文件阅读，也可以把整个仓库下载到本地，再使用 vscode 打开。

在 vscode 中打开 `.md` 文件后，可以点击编辑器右上角的预览按钮，也可以使用快捷键 `Ctrl + Shift + V` 查看 Markdown 的渲染效果。
